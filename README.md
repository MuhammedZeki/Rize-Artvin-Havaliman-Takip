# Rize-Artvin Havalimanı Takip

## 1. Proje Adı ve Açıklaması
**Rize-Artvin Havalimanı Takip**, Rize-Artvin Havalimanı'ndaki uçuş bilgilerini gerçek zamanlı olarak takip edebileceğiniz bir web uygulamasıdır. Kullanıcılar, iç ve dış hat uçuşlarının kalkış ve varış saatlerini, uçuş durumlarını ve olası gecikmeleri anlık olarak görüntüleyebilirler.

## 3. Kurulum
Projeyi çalıştırmak için aşağıdaki adımları izleyin:

```bash
git clone https://github.com/MuhammedZeki/Rize-Artvin-Havaliman-Takip.git
cd Rize-Artvin-Havaliman-Takip
npm install
npm start
```

Not: Projede kullanılan veritabanı veya API bağlantısı varsa `.env` dosyasını yapılandırmanız gerekebilir.

## 4. Kullanım
Uygulamayı çalıştırdıktan sonra tarayıcınızda `http://localhost:3000` adresine giderek Rize-Artvin Havalimanı'ndaki uçuş bilgilerini takip edebilirsiniz. Kullanıcılar, uçuş numarası veya destinasyon bilgisi girerek arama yapabilirler.

## 5. Özellikler
- Gerçek zamanlı uçuş bilgileri
- İç ve dış hat uçuşlarının takibi
- Uçuş arama ve filtreleme seçenekleri
- Temiz ve kullanıcı dostu arayüz
